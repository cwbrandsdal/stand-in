Accounts

Plans and value

API value prices every request at the provider's public API list price. The monthly pace extrapolates the last 30 days, or the recorded days for a new account; above 1× a plan is worth more than it costs.

Account moves

A session that moves to another account of the same provider pays to write its prompt cache again. Failover moves follow a failed request; affinity moves follow an idle gap longer than the affinity TTL.

Fast-mode refusals

Claude answers fast-mode requests from an account without usage credits with a 429; the tool then retries at standard speed. Turn fast mode off in that tool.

Data and settings

Alert settings

0 turns a check off. Projections use the burn rate of the last hour for 5-hour windows and the last 6 hours for weekly windows. Luna speaks critical alerts (limit reached, sign-in failing) at the next pause in a call or pushes them to the iPhone, and batches warnings. Large first cache writes and account moves stay here; Luna's drive brief summarizes them.
